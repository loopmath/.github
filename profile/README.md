## loopmath

Agent runs are experiments, treat them that way.

loopmath is a CLI your orchestrator calls around each coding task. It compares agent workflows, prices each one before the task, and learns from every run after.

```sh
pipx install loopmath
```

- [loopmath](https://github.com/loopmath/loopmath): the CLI. MIT, Python 3.11+, runs on your machine.
- [harness² plus loopmath](https://loopmath.ai/blog/harness2-plus-loopmath/): 95% of the gain at a quarter of the cost, on 40 coding tasks.
- [OCP](https://orchestrationcontextprotocol.io/): every run is written as one open OCP document.
